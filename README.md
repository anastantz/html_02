# 🌐 HTML5 - Títulos, parágrafos, linha horizontal (e um plus) 

	Atividade prática da disciplina Desenvolvimento Web em HTML5, CSS, Javascript e PHP do 2º período do curso superior de Jogos Digitais, implementando títulos h1 e h2, parágrafos e linha horizontal.
	
	## 📋 Enunciado 
	
	Roteiro de prática
Siga os passos necessários para realização dessa prática. Para isso, você precisará de um editor de textos – pode ser o próprio Bloco de Notas do Windows ou o Nano Editor do Linux, ou então algo um pouquinho mais avançado, como o software (livre/gratuito) Notepad++ e de um navegador – Google Chrome, Firefox, MS Edge etc.

• Em seu editor de textos, crie a estrutura básica de uma página HTML (tags doctype, html, head, title e body). Salve o documento com a extensão “html” ou “htm”.
• Dentro da tag body, insira um título principal, seguido de um parágrafo. Aqui você deverá utilizar as tags HTML adequadas para tais funções.
• Por fim, insira uma linha de separação horizontal no documento, procedida de um subtítulo e de um novo parágrafo de texto. Ao final, salve o documento e visualize o resultado no navegador.

## 💡 Além do óbvio: Experimentos com acessibilidade 

	Além do que foi proposto, experimentaram-se o uso de tags obsoletas e tags semânticas, a fim de observar seus diferentes comportamentos com leitores de tela. Para isso, utilizaram-se as tags obsoletas b e i, e as tags semânticas strong e em, para negrito e itálico respectivamente. O objetivo era observar as diferenças de comportamento em tags que, aparentemente, desempenham a mesma função.
	
		Para documentar esta parte adicional da atividade, outras tags foram aplicadas, como h3 e blockquote. 
		
		## 💭 Conclusões do experimento 
		
			O experimento demonstra que, visualmente, as tags obsoletas b e i, e suas correspondentes semânticas strong e em, desempenham o mesmo resultado, sem diferença perceptível. Porém, a nível semântico e estrutural, as tags semanticas strong e em denotam, tanto ao navegador quanto a softwares leitores de tela, trechos de ênfase em textos, coisa que as tags obsoletas não fazem. Embora usuários de leitores de tela precisem ativar configurações em seus softwares assistivos para que esses destaques sejam enfatizados, é importante frisar que a construção de páginas web semânticas é de suma importância para garantir a acessibilidade na web.
