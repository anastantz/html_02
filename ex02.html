Semântica versus Estética: Comportamento de tags obsoletas e tags HTML5

A Dra. Stantz pede desculpas pelo subtítulo longo. Esta seção, que não está inclusa no enunciado da atividade, visa demonstrar, através de uma pequena experiência, como tags obsoletas se comportam com leitores de tela, e como suas correspondentes atuais podem fazer a diferença.

Este parágrafo usa a tag b para negrito. A mudança aqui é estritamente visual.

Este parágrafo usa a tag strong para negrito. Aqui, a mudança também é semântica, ou seja: o navegador entenderá essa parte do conteúdo como um trecho de destaque, assim como leitores de tela como NVDA, Orca e Talkback.

Este parágrafo usa a tag obsoleta i para itálico. De novo, a alteração é meramente visual.

Já este parágrafo utiliza a tag em para itálico, com uma alteração semântica.

"Mas Ana, não vi nenhuma diferença. Por que devo usar as tags semânticas?

Aqui vem o pulo do gato: experimentando as tags obsoletas e semânticas, também não vi nenhuma diferença (trocadilho não intencional). Porém, eu posso ter acesso a trechos de texto destacados (negrito, itálico, sobrescrito, etc.) caso eu ative configurações específicas no meu NVDA, por exemplo, para anunciar trechos de ênfase. O NVDA, assim, poderia me informar que determinado trecho de texto tem algum destaque. Isso é muito útil para modos de leitura onde, por exemplo, eu estaria estudando algum texto.
